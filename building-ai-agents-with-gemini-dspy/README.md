# Retired: Building AI Agents with Gemini & DSPy

This August 21, 2025 livestream demo is retired because its DSPy dependency
introduces LiteLLM. The installable project, launchers and examples have been
removed so following this repository does not install that dependency chain.

The original material remains in [Git history](https://github.com/Smarter-Dev/livestream-projects/tree/83fc5dbaa8456544360c879befae75f86b644a8e/building-ai-agents-with-gemini-dspy)
for historical reference. Do not install or run the historical dependencies.
For current Gemini integration examples, see the
[Google Gen AI SDK documentation](https://googleapis.github.io/python-genai/).
